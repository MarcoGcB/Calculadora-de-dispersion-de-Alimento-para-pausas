# Calculadora de Dispersión de Alimento para Pausas 🦐

Este proyecto es una aplicación Flutter diseñada para calcular y gestionar la **dispersión de alimento en procesos automáticos de camaroneras**.  
Su objetivo es optimizar la alimentación en rangos de tiempo y pausas, mejorando la eficiencia del proceso.

---

## 🚀 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MarcoGcB/Calculadora-de-dispersion-de-Alimento-para-pausas.git
2. Entra en la carpeta del proyecto:
   ```bash
   cd flutter_dosis_1
3. Instala las dependencias:
   ```bash
   flutter pub get
4. Ejecución
   ```bash
   flutter run
